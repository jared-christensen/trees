# trees v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go CLI, `trees`, that lists git worktrees and branches with their state, cleans up the ones that are done, and creates and switches worktrees, on any git host.

**Architecture:** Thin cobra commands over small internal packages. Everything git-related shells out to the `git` binary through one runner. A pure classifier turns gathered facts into states, so the safety rules are unit-tested without git. PR status comes from an optional provider (GitHub via `gh`) that can fail silently.

**Tech Stack:** Go 1.23+, `github.com/spf13/cobra`, `github.com/BurntSushi/toml`, GoReleaser. No other dependencies. Colors are plain ANSI codes.

**Spec:** `docs/superpowers/specs/2026-10-28-trees-design.md`

## Global Constraints

- Module path: `github.com/jared-christensen/trees`. Binary name: `trees`.
- Requires git 2.38+ (`merge-tree --write-tree`). Below that, exit with: `trees needs git 2.38 or newer (you have X.Y.Z).`
- macOS and Linux. zsh and bash shell integration.
- Never delete remote branches. Never pass `--force` to `git worktree remove`.
- Read-only except `clean` and `create`.
- Defaults: stale threshold 14 days; fetch timeout 5 seconds; worktree path `{repo_parent}/{repo}.{name}`.
- Per-repo settings live in the user config (`~/.config/trees/config.toml`, honoring `XDG_CONFIG_HOME`) under `[repos."<abs main checkout path>"]`. trees never reads config from inside a repo.
- Every git call sets `GIT_TERMINAL_PROMPT=0` so nothing waits for a password.
- Output wording: states are exactly `still in use`, `stale, take a look`, `safe to delete`. Section titles are exactly `Worktrees` and `Branches not in any worktree`.

## Review Focus

1. **Paths with spaces** (the author's projects live in `~/Personal Projects`). Every command must work when the repo path contains a space. Pinned in Task 1 (test helper creates repos under a directory with a space) and Task 8.
2. **Repo with no remote.** Compare against local `main`/`master`, skip fetching with a one-line note, and still allow `clean`. Pinned in Task 2 and Task 6.
3. **Running from inside a linked worktree or a subdirectory.** trees must find the main checkout and report the whole repo. Pinned in Task 1.
4. **`gh` missing, not logged in, or the repo isn't on GitHub.** List stays fast and complete, just without PR lines. Pinned in Task 4.
5. **Worktree folder deleted by hand, or a locked worktree.** List shows `(folder missing)` / `(locked)`; clean prunes the missing one and skips the locked one with a reason, without erroring. Pinned in Task 2 and Task 6.

### Task 2: Inventory

**Files:** Create: `internal/inventory/inventory.go`, Test: `internal/inventory/inventory_test.go`

**Interfaces:**
- Consumes: `git.Runner`, `git.MainCheckout`, `gittest`.
- Produces:
  ```go
  type Worktree struct {
      Path, Branch string   // Branch "" when detached
      Head        string
      Detached, Missing, Locked bool
      Dirty       int      // count of `status --porcelain` lines; 0 when Missing
  }
  type Branch struct {
      Name, SHA, Upstream string
      UpstreamGone       bool
      Unpushed           int       // rev-list --count <b> --not --remotes
      LastCommit         time.Time
      Worktree           *Worktree // nil if not checked out anywhere
  }
  type Inventory struct {
      Main         string     // main checkout path
      MainBranch   string     // branch checked out in main checkout
      MainDirty    int
      Base         string     // e.g. "origin/main", or "main" with no remote
      HasRemote    bool
      FetchErr     error      // nil if fetched or skipped on purpose
      Branches     []Branch   // excludes the default branch

  }
  type Options struct { Fetch bool; FetchTimeout time.Duration }
  func Load(ctx context.Context, mainPath string, opt Options) (*Inventory, error)

- Parse `worktree list --porcelain` (`worktree`, `HEAD`, `branch`, `detached`, `locked`, `prunable` lines). The main checkout is the first entry and is not a `Branch` unless it has a non-default branch checked out.

### Task 3: Merged detection and state rules

**Files:** Create: `internal/merged/merged.go`, `internal/status/status.go`, Test: `internal/merged/merged_test.go`, `internal/status/status_test.go`

**Interfaces:**
- Produces:
  - `func merged.IsMerged(ctx, r git.Runner, base, branch string) (bool, error)`
  - `func merged.HasOwnCommits(ctx, r git.Runner, branch string) bool`
  - ```go
    type State int // InUse, Stale, SafeToDelete
    func (s State) String() string // exactly the three phrases in Global Constraints
    type PRState string // "", "OPEN", "MERGED", "CLOSED"
    type Facts struct {
        Dirty int; OpenPR, MergedPR, ClosedPR int // PR numbers, 0 = none
        OwnCommits, Merged bool
        LastCommit time.Time; Now time.Time; StaleAfter time.Duration
        Unpushed int; UpstreamGone bool
    }
    func status.Classify(f Facts) (State, []string)
    ```

IsMerged algorithm:
```
if merge-base --is-ancestor <branch> <base> succeeds → true
tree, err := merge-tree --write-tree <base> <branch>   // exit 1 = conflicts → false, nil
return tree == rev-parse <base>^{tree}
```
(`merge-tree --write-tree` prints the tree OID on its first line.)

HasOwnCommits: the oldest entry of `reflog show --format=%H refs/heads/<branch>` is the sha the branch was created at. Own commits = that sha differs from the current tip. No reflog → true (assume it has work).

Classify precedence, exactly as the spec's "Which state wins" list: (1) `Dirty>0` or `OpenPR>0` → InUse; (2) `!OwnCommits` → InUse until `Now-LastCommit > StaleAfter`, then Stale; (3) `Merged` → SafeToDelete; (4) `ClosedPR>0` or older than `StaleAfter` → Stale; (5) InUse.

Reasons, in this order, each only when true: `N uncommitted file(s)`, `PR #N open`, `nothing committed yet`, `PR #N merged` (or `merged into <base>` when no PR), `branch itself is already merged` (when state isn't SafeToDelete but Merged), `PR #N closed`, `N commit(s) never pushed`, `remote branch deleted`. If none apply: `not merged yet`.

- Layout: the spec's list example. Header `<repo name>  <path with ~>, compared to <Base>`. ### Task 8: `trees create`

**Files:** Create: `internal/naming/naming.go`, `internal/cli/create.go`, Test: `internal/naming/naming_test.go`, `internal/cli/create_test.go`

**Interfaces:**
- Consumes: `config.Settings`, `shell.Cd`, `inventory.Load`.
- Produces:
  - `func naming.FolderName(branch string) string`: `/` → `-`.
  - `func naming.WorktreePath(tmpl, repoMain, branch string) string`: replaces `{repo_parent}`, `{repo}`, `{name}`; expands leading `~`.
  - `func naming.Check(pattern, mode, branch string) (warning string, err error)`: empty pattern → `"", nil`; mismatch with `warn` → warning text `"<branch>" doesn't match your name pattern <pattern>.`; with `require` → error with the same text.
- `create <branch>` behavior, in order:
  1. Name check.
  2. Branch already checked out in a worktree → print `<branch> is already in <path>.` and switch there (exit 0).
  3. Fetch (soft, same timeout as list).
  4. Local branch exists → `worktree add <path> <branch>`. Else `origin/<branch>` exists → `worktree add --track -b <branch> <path> origin/<branch>`. Else → `worktree add -b <branch> <path> <Base>` with `--no-track`.
  5. Target path exists → error `<path> already exists.`, nothing created.
  6. Run each `Setup` command with `sh -c` in the new worktree, streaming output; first failure stops setup, prints which command failed, and leaves the worktree in place.
  7. `shell.Cd(path)`.
